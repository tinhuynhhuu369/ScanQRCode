# ScanQRCode

App Python nhỏ để đọc mã QR từ file ảnh.

## Cài đặt

```bash
pip install -r requirements.txt
```

## Chạy

```bash
python scan_qr.py
```

## Cách dùng

1. **Kéo thả** file ảnh vào vùng giữa cửa sổ, hoặc
2. Bấm **"Chọn ảnh..."** (hoặc click vào vùng giữa) để chọn file. Cũng có thể dán đường dẫn vào ô trên cùng rồi nhấn **Enter**.

Nội dung QR hiện ở ô **Kết quả**, bấm **Copy** để chép vào clipboard. Ảnh có nhiều mã QR sẽ hiện tất cả.

Hỗ trợ: PNG, JPG, BMP, GIF, WEBP, TIFF; đường dẫn có tiếng Việt vẫn đọc được.
